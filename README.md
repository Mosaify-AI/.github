# Mosaify organization configuration

This repository owns Mosaify's public GitHub organization profile, handbook, and shared community health files.

- `profile/README.md` renders on the [Mosaify-AI organization overview](https://github.com/Mosaify-AI).
- [`handbook/README.md`](handbook/README.md) is the canonical public Mosaify handbook.
- Organization-wide community health files belong at the repository root when they are introduced.

Changes should be reviewed through pull requests before they affect the public organization profile.
