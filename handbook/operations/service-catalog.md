# Tools and services catalog

This catalog is the public inventory of the material tools, hosted services, frameworks, and delivery systems evidenced in the renamed Mosaify repositories as of 15 August 2026. It describes checked-in integration state, not vendor-account state.

## Lifecycle vocabulary

- **Active**: the integration is merged and used by current code, workflows, or documented local operations. This does not by itself prove that a production deployment has enabled it.
- **Adoption in progress**: implementation or production controls remain in open work or behind rollout gates.
- **Development only**: intentionally limited to local development, tests, fixtures, or build-time use.
- **Planned**: a boundary or placeholder exists, but the integration is not implemented.
- **Deprecated**: still present only for a bounded compatibility or migration reason.
- **Archived**: retained for reference and no longer an active delivery surface.

When production enablement cannot be established from public repository evidence, the catalog says **unconfirmed**. That is an evidence gap, not permission to enable the system.

## Confirmed absences and open evidence gaps

- No production hosting or deployment vendor is established by checked-in manifests or workflows.
- No production PostgreSQL vendor, S3-compatible storage vendor, SMTP vendor, secret manager, alert destination, or support-ticketing vendor is established by public repository evidence.
- No confirmed design, chat, CRM, sales, or business-operations platform integration was found. Product copy, icons, installed desktop apps, browser sessions, or an account existing at a vendor are not integration evidence.
- `mosaify-mcp` has no GitHub Actions workflow and its API adapter is planned, not active.
- PostHog, Sentry, Turnstile, and first-party feedback are present on open adoption branches, not current merged manifests.
- Production retention settings cannot be verified from code alone. Public runbooks state required targets; a restricted operating record must confirm the configured values without publishing account names or dashboard URLs.

## Maintenance rule

Update this page and the applicable public runbook in the same coordinated change that adds, removes, materially expands, or changes the data boundary of a tool or service. Private account names, dashboard URLs, secret-manager references, alert destinations, customer data, credentials, private media URLs, and incident evidence belong only in the restricted supplement described by `mosaify-workspace/docs/README.md`.
